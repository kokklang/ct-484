# 🚀 Project: CT-484 (Frontend-Backend API Connection Practice)

โปรเจกต์นี้จัดทำขึ้นเพื่อฝึกฝนทักษะการพัฒนาเว็บและแอปพลิเคชันแบบแยกส่วน **Frontend (Flutter)** และ **Backend (Laravel)** โดยมุ่งเน้นไปที่การเรียนรู้ระบบการทำงานของ API, สถาปัตยกรรมเครือข่าย และโครงสร้าง (Syntax) ของภาษา

---

## 🎯 วัตถุประสงค์ของโปรเจกต์ (Project Objectives)

*   **Practice Full-Stack Architecture:** ฝึกการแบ่งส่วนการทำงานระหว่างหน้าบ้าน (Frontend) และหลังบ้าน (Backend) อย่างเป็นระบบ
*   **Master API Concepts:** เรียนรู้กระบวนการรับ-ส่งข้อมูล การเชื่อมต่อ และการจัดการข้อมูลผ่าน  API
*   **Logic & State Management:** ฝึกกระบวนการคิดและออกแบบ Logic การเก็บข้อมูล การส่งค่าผ่านตัวแปร และการจัดการสถานะ (State) ไปยังหน้าต่างๆ 
*   **AI-Assisted Learning:** ฝึกฝนการใช้งาน AI ในฐานะผู้ช่วยเขียนโค้ด (Coding Assistant) โดยผู้พัฒนาทำหน้าที่เป็นผู้ Review, ตรวจสอบความถูกต้อง และนำมาปรับใช้จริง

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

### 📱 Frontend (Client)
*   **Flutter (Dart):** ใช้สำหรับพัฒนาส่วนติดต่อผู้ใช้ (UI) และจัดการ Logic การรับ-ส่งค่าระหว่างหน้าจอ

### ⚙️ Backend (Server / API)
*   **Laravel (PHP):** ใช้สำหรับสร้าง API, จัดการฐานข้อมูล (Database Management) และควบคุมหลังบ้านการจัดการข้อมูล

---

## 📂 โครงสร้างระบบ

โปรเจกต์นี้ใช้วิธีคิด Logic การรับส่งข้อมูลโดยผู้พัฒนาเอง และเชื่อมต่อผ่าน API ดังนี้:

```text
[ Flutter Frontend ]  <--->  [  API ]  <--->  [ Laravel Backend ]
  - UI & Screen States         (JSON Data)             - Route & Controllers
  - Local Variables                                    - Database / Logic
```


## 💡 สิ่งที่ได้เรียนรู้จากโปรเจกต์นี้ (Key Takeaways)
*   เข้าใจไวยากรณ์ (Syntax) และโครงสร้างการทำงานของภาษา **Dart (Flutter)** และ **PHP (Laravel)** ในเบื้องต้น
*   การออกแบบโครงสร้างข้อมูล และการจัดการตัวแปรเพื่อส่งต่อข้อมูลไปยังหน้าต่าง ๆ
*   ทักษะการเป็น **Code Reviewer** ตรวจสอบและคัดกรองโค้ดที่สร้างโดย AI เพื่อนำมาพัฒนาต่อยอดให้ตรงตามความต้องการ
